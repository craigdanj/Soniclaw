Run a fixture with `cargo run -p soniclaw-dsp-suite --locked --offline -- EXAMPLE NEW_DIRECTORY`. Use a destination that does not yet exist. Add `--release` for profiling examples. The fixtures write JSON measurements and audio, filter response data or model files, depending on the example. The hybrid instrument guide also documents a live audio example.
