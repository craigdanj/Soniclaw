# Six-feature release series

The authorized sequence is one feature per minor release, with detailed feature documentation, migration notes, tests and a source archive at each step.

| Version | Feature | Status |
|---|---|---|
| 0.10.0 | Preset and asset browser | Complete |
| 0.11.0 | Advanced sampler and SFZ subset | Complete |
| 0.12.0 | Unified input/output management | Complete |
| 0.13.0 | Automation editing toolkit | Complete |
| 0.14.0 | Live CLAP rack and hosted editors | Complete |
| 0.15.0 | Expanded compatibility and release testing | Complete |

Each guide must cover user workflow, API examples, lifecycle/thread ownership, persistence, migrations, limits, error/recovery behavior and evidence. Native DAW/hardware/platform checks must remain pending unless actually run.
