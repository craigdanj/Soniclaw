# Soniclaw 0.12.0 — Unified input/output management

Release date: 2026-11-17.

## Feature

Added shared input/output selection and channel maps, stereo duplex processing/MIDI delivery, muted-by-default monitoring, managed recording and coordinated close/reconnect with retained take errors.

Read the [detailed guide](../UNIFIED_AUDIO.md) for user workflow, API, runnable examples, lifecycle/thread ownership, persistence/migrations, limits, errors and recovery.
