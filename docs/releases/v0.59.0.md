# Soniclaw 0.59.0 — Dynamic latency and bus reconfiguration

Release date: 2026-11-18.

## Added

Stopped, staged native topology replacement preserves latest state, validates explicit bus/channel routes and latency budgets, prepares complete PDC graphs before revision-checked commit, and leaves retired callbacks silent.

Read the [feature guide](../DYNAMIC_RECONFIGURATION.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.

## Fixed

Full-workspace testing exposed an intermittent one-sample zero at a streamed freeze page boundary. Integer-position linear interpolation now avoids requesting its zero-weight lookahead; offline playback preflights the complete lookahead and rejects observed underruns before a freeze can publish. A deterministic interpolation regression and the complete streamed waveform test cover the correction. The initial failing test log is retained in the validation folder.

## Compatibility

Workspace/internal package metadata advances to 0.59.0. Existing product identities remain stable. This remains pre-1.0; feature-specific schema changes and dependencies are described in the guide.
