## Public APIs and adoption

- `dsp::streaming::PitchShifter` / `PitchSettings`: prepared mono/stereo STFT pitch shifting, local spectral-peak phase locking, optional spectral-flux phase resets, aligned dry/wet latency and bounded invalid-call behavior.
- `dsp::streaming::TimeStretcher` / `StretchSettings`: linked-stereo WSOLA with explicit partial input acceptance, bounded grain budgets, finish/drain, exact configured output duration and reset/reuse.
- `soniclaw-pitch-time`: source/A-B pitch/stretched WAV export plus measured pitch, latency, diagnostics and partition-equivalence report.

These are opt-in APIs. Existing project PitchShift nodes and offline functions keep their prior behavior. Settings use schema 1; histories are not serialized. The time stretcher has variable I/O and a fixed per-stream ratio; an application FIFO/transport adapter is required for a fixed-rate host chain. Formant preservation and commercial vocal-quality parity are not claimed.

The full Linux workspace passed 262 Rust tests (one optional codec test ignored), 15 Python tests and warnings-denied Clippy/documentation. Fresh Linux CLAP export/host/live-rack checks and portable ARM64 cross-checks are linked from the verification report. Hardware, external DAW, Windows/macOS runtime and listening acceptance remain pending.
