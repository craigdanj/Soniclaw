# Soniclaw 0.19.0 — Audio format manager

Release date: 2026-11-17.

## Feature

A common optional libsndfile-backed WAV/AIFF/FLAC API with encoding, seekable decoding, metadata, bounded asset loading and project/bundle integration; portable WAV APIs remain available.

Read the [detailed guide](../AUDIO_FORMATS.md) for user workflow, API, runnable examples, lifecycle/thread ownership, persistence/migrations, limits, errors and recovery.

## Compatibility and migration

All workspace/internal package and format metadata advance to 0.19.0. Existing exported product and parameter identities remain stable. New fields/APIs and reader compatibility are described in the feature guide. No publication or untested platform acceptance is implied.

## Validation

Fresh local checks and exact limitations are in the [report](../validation/v019/REPORT.md). Historical notes/evidence retain their original scope. DAW, physical-device and native platform acceptance are claimed only when actually executed.
