# Soniclaw 0.52.0 — Unified reference studio

Release date: 2026-11-18.

## Added

A unified desktop studio template with live session playback, reusable portable project folders, arrangement/piano-roll and automation editors, stem recording, reversible freeze, parameter mixing and explicitly trusted CLAP insert ownership/state capture.

Read the [feature guide](../REFERENCE_STUDIO.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
