# Soniclaw 0.23.0 — VST3 hosting

Release date: 2026-11-17.

## Feature

Common CLAP/VST3 product controls, trusted factory scanning, native VST3 state and timed parameters, a bounded stereo audio/MIDI worker bridge, native editors and a workbench VST3 panel.

Read the [detailed guide](../VST3_HOSTING.md) for workflow, public API, runnable examples, lifecycle/thread ownership, persistence, migration, limits and recovery.

## Compatibility and migration

Workspace/internal packages and format metadata advance to 0.23.0. Existing exported product and parameter identities stay stable. See the guide for additive fields, backend requirements and platform scope. This remains pre-1.0.

## Validation

See the [verification report](../validation/v023/REPORT.md) for actual commands/results and limitations. No unrun hardware, DAW or operating-system acceptance is implied.
