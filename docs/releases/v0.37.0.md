# Soniclaw 0.37.0 — Reusable mixer toolkit

Release date: 2026-11-18.

## Added

Prepared stereo channel strips with smoothed gain/pan, mute/solo, groups, pre/post sends, sample-offset automation, atomic meters and reusable UI controls with a stem-rendering example.

Read the [feature guide](../MIXER.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
