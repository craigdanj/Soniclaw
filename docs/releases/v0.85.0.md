# Soniclaw 0.85.0 — Native mixdown and integrated DAW workflows

Release date: 2026-11-20.

## Added

Integrates trusted continuous native offline rendering into Studio export and freeze, captures post-strip, bus and return stems in one graph pass with source-specific latency trimming, and provides an end-to-end recording, MIDI recovery, portable session and delivery example.

Read the [feature guide](../DAW_DELIVERY.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.

## Integration evidence

The owned Linux protocol fixture completed the recording → MIDI/recovery → portable save/reopen → routed native export example. Six files contained 6144 frames each; the expected pre-master bus/return relationship matched exactly. Native note identities and expression remained continuous across blocks, and obsolete offline leases rejected processing after owner destruction. Independent regression tests cover 13/20/16/25-frame source/master latencies and cancellation after preparation. See the [JSON evidence](../validation/v0_85_0/integrated.json).
