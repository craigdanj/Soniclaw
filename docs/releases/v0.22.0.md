# Soniclaw 0.22.0 — Expanded hosted editors

Release date: 2026-11-17.

## Feature

Native parent attachment, owned X11 editor windows, resize and scale negotiation, stable reopening, persisted editor preferences and bounded CLAP timer/POSIX FD host services.

Read the [detailed guide](../HOSTED_EDITORS.md) for workflow, public API, runnable examples, lifecycle/thread ownership, persistence, migration, limits and recovery.

## Compatibility and migration

Workspace/internal packages and format metadata advance to 0.22.0. Existing exported product and parameter identities stay stable. See the guide for additive fields, backend requirements and platform scope. This remains pre-1.0.

## Validation

See the [verification report](../validation/v022/REPORT.md) for actual commands/results and limitations. No unrun hardware, DAW or operating-system acceptance is implied.
