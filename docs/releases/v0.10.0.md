# Soniclaw 0.10.0 — Preset and asset browser

Release date: 2026-11-17.

## Feature

Added searchable preset catalogs, tags, favourites, banks, background-rendered previews and audible audition, missing-asset checks, scoped relocation and portable preset export.

Read the [detailed feature guide](../PRESET_BROWSER.md) for the complete user workflow, API, examples, lifecycle/thread ownership, persistence/migrations, errors, bounds and recovery behavior.

## Compatibility and migration

All workspace/internal package and format metadata advance to 0.10.0. Existing product IDs and parameter IDs remain stable. See the feature guide for new optional fields, constructor changes and schema details. This source release does not publish crates or assert untested platform support.

## Validation

Fresh results and exact limitations are recorded in the [validation report](../validation/v010/REPORT.md). Existing reports/notes retain their original scope. Physical devices, real DAW sessions and native platform acceptance are reported only when actually run.

## Getting started

Follow the commands and runnable walkthrough in the feature guide. The workbench and SDK tools integrate the feature. This release is one step in the [six-feature delivery sequence](../DELIVERY_PLAN.md).
