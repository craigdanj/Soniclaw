# Soniclaw 0.14.0 — Live CLAP rack and floating editors

Release date: 2026-11-17.

## Feature

A main-thread-owned serial CLAP rack with a bounded stereo callback bridge, live parameter controls, output-event observation, floating-editor lifecycle and workbench device integration.

Read the [detailed guide](../LIVE_CLAP_RACK.md) for user workflow, API, runnable examples, lifecycle/thread ownership, persistence/migrations, limits, errors and recovery.
