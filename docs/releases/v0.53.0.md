# Soniclaw 0.53.0 — Scalable arrangement and piano-roll editors

Release date: 2026-11-18.

## Added

Reusable virtualized arrangement and full 128-key piano-roll surfaces with both-axis scrolling/zoom, independently resized track rows, marquee and multiple selection, grouped validated moves/deletes and undo/redo, plus saved viewport state and reference-studio integration.

Read the [feature guide](../SCALABLE_EDITORS.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.

## Compatibility

Workspace/internal package metadata advances to 0.53.0. Existing product identities remain stable. This remains pre-1.0; feature-specific schema changes and dependencies are described in the guide.
