# Soniclaw 0.48.0 — Multicore graph processing

Release date: 2026-11-18.

## Added

Dependency-level DSP worker execution with fixed node ownership, deterministic fan-in and existing delay compensation, exposed through a bounded timestamped callback bridge with explicit latency, silence-on-miss and atomic deadline telemetry.

Read the [feature guide](../PARALLEL_GRAPH.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
