# Soniclaw 0.51.0 — Native PipeWire integration

Release date: 2026-11-18.

## Added

Optional native Linux PipeWire DSP filter backend with named per-channel input/output ports, explicit non-lingering graph links, bounded registry snapshots, prepared callback buffer splitting and driver/processing timing telemetry; includes a private software-server acceptance probe.

Read the [feature guide](../PIPEWIRE.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
