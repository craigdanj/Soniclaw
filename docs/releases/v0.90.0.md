# Soniclaw 0.90.0 — Anti-aliased nonlinear processing

Release date: 2026-11-20.

## Added

Adds reusable ADAA hard clipping, tanh and cubic saturation, stable near-equal-input handling, smoothed controls, exact integer latency/padding, oversampling composition and coherent spectral/WAV comparisons against matched-filter naive processing.
