# Soniclaw 0.28.0 — Multichannel hosting and delay compensation

Release date: 2026-11-17.

## Added

Explicit mono/stereo/multichannel bus DAGs with per-channel feed-forward latency compensation, native VST3 sidechain/auxiliary activation and a bounded multiple-bus worker bridge.

Read the [feature guide](../HOST_CHANNELS.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
