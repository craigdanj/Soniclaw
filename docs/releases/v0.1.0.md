# Soniclaw 0.1.0

Release date: 2026-11-15. Originally named Sonora.

## Highlights

The initial foundation provides modular Rust building blocks for native audio
applications, instruments and effects, with a desktop synthesizer and an
offline rendering example.

## Added

- Core processing types and DSP building blocks.
- Synthesizer and sampler foundations, serial processing chains and DAG routing.
- Output-device hosting, MIDI and egui controls.
- WAV I/O, JSON presets and a format-independent plug-in lifecycle.
- An application generator and desktop/offline examples.

## Compatibility and migration

This was the initial developer release. There was no earlier framework release
to migrate from. Later releases add capabilities and may change pre-1.0 APIs.
For the current package-name migration, see the [Soniclaw rename guide](../RENAMING.md).

## Validation and limitations

These notes summarize the preserved 0.1.0 changelog. No additional 0.1.0
validation was performed while preparing these notes. The initial foundation
does not establish native plug-in-format support or JUCE feature parity.

See the [current setup instructions](../../README.md) and [changelog](../../CHANGELOG.md)
for subsequent changes; current documentation describes the latest source.
