# Soniclaw 0.99.0 — Advanced sampler region playback

Release date: 2026-11-21.

## Added

Single-voice resident sample regions with reverse and ping-pong playback, explicit wrap-overlap fades, seek/speed controls, loop release into tails and an offline bounded loop matcher.

Read the [feature guide](../DSP_PLAYBACK.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
