# Soniclaw 0.74.0 — Independent multichannel recording

Release date: 2026-11-19.

## Added

Independent hardware-channel routes feed track monitors and native-width recording stems; gap-free linear dry recordings place automatically as editable regions, with input-quality metadata and portable routes.

Read the [feature guide](../DAW_MULTICHANNEL.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
