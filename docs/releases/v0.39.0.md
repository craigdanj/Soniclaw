# Soniclaw 0.39.0 — Microtuning support

Release date: 2026-11-18.

## Added

Validated absolute tuning tables, bounded Scala SCL/KBM imports, synth/sampler frequency integration, unmapped-key handling and optional project persistence, with an audible just-intonation demo.

Read the [feature guide](../MICROTUNING.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
