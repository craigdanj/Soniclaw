# Soniclaw 0.80.0 — Transient and grouped elastic editing

Release date: 2026-11-20.

## Added

Detect and grid-snap reference transients, render linked mono/stereo microphone groups through one shared-decision multichannel WSOLA stream, apply verified caches atomically with undo/redo, and persist group recipes with portable projects. Add the reference group editor and four-microphone validation example.

Read the [feature guide](../DAW_ELASTIC.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
