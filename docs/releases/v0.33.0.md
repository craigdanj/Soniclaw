# Soniclaw 0.33.0 — Themeable audio UI toolkit

Release date: 2026-11-17.

## Added

Serializable audio UI themes, normalized knobs/faders with fine and stepped interaction, modulation rings, typed toggles/enums, prepared SVG and filmstrip assets, and a native theme gallery with framebuffer snapshots.

Read the [feature guide](../UI_TOOLKIT.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.

## Compatibility

Workspace/internal package metadata advances to 0.33.0. Existing product identities remain stable. This remains pre-1.0; feature-specific schema changes and dependencies are described in the guide.
