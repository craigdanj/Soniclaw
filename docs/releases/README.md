# Release notes

Soniclaw maintains a separate release note for every major and minor release,
including pre-1.0 releases such as 0.1.0. Patch releases are recorded in the
changelog; give them a separate note when migration or compatibility changes
need explanation.

| Release | Date | Summary |
|---|---|---|
| [0.3.0](v0.3.0.md) | 2026-11-15 | Performance, embedded editors, host compatibility, effects, multisampling and format/package tools |
| [0.2.0](v0.2.0.md) | 2026-11-15 | Duplex audio, recording, automation, CLAP export and audio UI controls |
| [0.1.0](v0.1.0.md) | 2026-11-15 | Initial modular audio framework |

The framework was called Sonora when these releases were first prepared. It
was renamed to Soniclaw on 2026-11-16 without changing version 0.3.0. The
0.3.0 notes record that follow-up and link to migration guidance. These notes
were organized on 2026-11-16 from the existing changelog and validation records;
they do not imply that additional historical tests were run.

Use the [template](TEMPLATE.md) and [release checklist](../RELEASE.md#release-notes-and-version-checklist)
for future releases. Keep [CHANGELOG.md](../../CHANGELOG.md) as the concise
chronological record and these pages as the fuller user-facing release notes.
