The framework was called Sonora when releases 0.1–0.3 were first prepared. It
was renamed to Soniclaw on 2026-11-16 without changing version 0.3.0. The
0.3.0 notes record that follow-up and link to migration guidance. The 0.1–0.3 notes
were organized on 2026-11-16 from the existing changelog and validation records;
they do not imply that additional historical tests were run.

Use the [template](TEMPLATE.md) and [release checklist](../RELEASE.md#release-notes-and-version-checklist)
for future releases. Keep [CHANGELOG.md](../../CHANGELOG.md) as the concise
chronological record and these pages as the fuller user-facing release notes.
