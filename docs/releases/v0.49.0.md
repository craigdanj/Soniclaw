# Soniclaw 0.49.0 — Broader plug-in isolation

Release date: 2026-11-18.

## Added

Explicit CLAP helper-process hosting for main/auxiliary input-output ports, a timestamped callback bridge, bounded RPC timeouts, opaque checkpoints and fresh-process recovery with a restart budget; existing VST3 isolation remains available.

Read the [feature guide](../EXPANDED_ISOLATION.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.

## Compatibility

Workspace/internal package metadata advances to 0.49.0. Existing product identities remain stable. This remains pre-1.0; feature-specific schema changes and dependencies are described in the guide.
