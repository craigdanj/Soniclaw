# Soniclaw 0.2.0

Release date: 2026-11-15. Originally named Sonora.

## Highlights

This release extends the framework into live input processing and recording,
adds real CLAP exports, and expands reusable controls for audio applications.

## Added and changed

- Native duplex input/output, channel maps, validated rate/buffer requests,
  saved sessions and control-thread device recovery.
- Monitored and bypassed live effects, plus dry/processed background stereo
  PCM16 recording with loss accounting and duration preservation.
- Sample-offset parameter automation, separate main/sidechain bus contracts,
  a sidechain compressor, graph latency compensation and suspend/resume.
- CLAP gain/synth exports with state, parameters, ports and lifecycle support,
  a CLAP project template and a bundle helper.
- Knobs, XY controls, waveforms, keyboard, envelope/EQ controls and meter ballistics.
- Live FX/Recorder and UI gallery examples.

## Compatibility and migration

This is a pre-1.0 developer release. Duplex configuration, recording and
automation require adopting the corresponding new interfaces; an output-only
application does not automatically become an input processor. The internal
sidechain bus contract at this version does not expose a CLAP sidechain port.
For the later package rename, see the [migration guide](../RENAMING.md).

## Validation

The historical changelog records expanded integration, allocation and recording
tests and upstream CLAP validation. No new 0.2.0 runs or numerical performance
claims were made when preparing these notes. Preserved source and evidence
remain in the [benchmark area](../../benchmarks/) and [validation records](../validation/).

## Known limitations

Native hardware and interactive DAW validation remained pending. This version
did not include embedded CLAP editors, VST3/AU wrappers, exported CLAP sidechain
ports or native installers, and did not claim JUCE feature parity. Some of
these are subsequently addressed in [0.3.0](v0.3.0.md).

See the [current examples and setup](../../README.md) and [changelog](../../CHANGELOG.md).
