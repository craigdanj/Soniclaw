# Soniclaw 0.89.0 — Reusable multi-rate oversampling

Release date: 2026-11-20.

## Added

Adds independent 2x/4x/8x half-band FIR oversampling, quality settings, integer latency reporting, a generic AudioProcessor wrapper with MIDI/clock retiming, bounded prepared buffers and standalone audio examples.

Read the [feature guide](../DSP_OVERSAMPLING.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
