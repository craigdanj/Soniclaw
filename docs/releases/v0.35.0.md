# Soniclaw 0.35.0 — Audio and MIDI clip toolkit

Release date: 2026-11-17.

## Added

Validated audio/MIDI clip editing, looped frame/beat playback, seek recovery, latency alignment and reusable arrangement/piano-roll views, with a native editor and WAV rendering demo.

Read the [feature guide](../CLIPS.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
