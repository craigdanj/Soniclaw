# Soniclaw 0.70.0 — Media audit and project consolidation

Release date: 2026-11-19.

## Added

Conservative media dependency audit and verified consolidated portable copies, stale-plan rejection, freeze/warp dependency retention and preserved original files.

Read the [feature guide](../STUDIO_MEDIA_AUDIT.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.

## Fixed

- Completed/consumed job handles no longer retain unbounded replacement keys; key lifetime follows the retained reservation.
- Streamed recording primes disk pages at the selected start before the first callback. `Document::compile_streamed_at` supports stopped preparation for a caller-supplied transport start.
- Both regressions were reproduced with failing tests before correction and pass after correction; see validation evidence.

## Compatibility

Workspace/internal package metadata advances to 0.70.0. Existing product identities remain stable. This remains pre-1.0; feature-specific schema changes and dependencies are described in the guide.
