# Soniclaw 0.3.0

Release date: 2026-11-15.

## Highlights

This release expands performance tooling, embedded plug-in editors, host
compatibility, effects, sampled instruments and native format/package workflows.

## Added and changed

- Scoped CLAP denormal handling, processing optimizations and reproducible
  v0.2/v0.3 CPU benchmarks using a frozen baseline.
- Host-parented egui editors with resize/scale/focus handling and bounded
  begin/value/end parameter gestures with backpressure.
- Real CLAP sidechain ports and an independent exported-ABI host for
  automation, state, buses, callback stress, heap checks and GUI interaction.
- Parametric EQ, compressor, peak limiter, gate, chorus, reverb, partitioned
  FFT convolution and oversampled drive.
- Multisample banks, velocity layers, round robin, sustain, pitch bend and
  crossfaded stealing, plus a separate bounded background WAV transport.
- A four-product reference bundle, a standalone drum application, pinned
  static VST3/AUv2 wrapper integration, app/effect/sampler templates, package
  recipes and license collection.
- Shared UI dependencies upgraded to egui/eframe 0.36.1. Preparation accepts
  finite rates up to 1,536,000 Hz; actual devices negotiate supported rates.

## Compatibility and migration

Existing gain/synth product and parameter identities are retained. Platform
wrapper and editor dependencies require the native development prerequisites
described in the [setup instructions](../../README.md) and [format guide](../FORMATS.md).

## Validation

The Linux validation records 55 Rust tests, upstream CLAP validation
(183 passed, 52 skipped, one warning), VST3 validation (188 passed), embedded
X11 interaction and independent host checks. See the [full validation report](../VALIDATION.md) for conditions and limits.

## Known limitations

Native macOS/Windows runtime acceptance, AUv2 compilation, real DAW project
round trips, physical audio loopback/unplug testing, signing/notarization and
Windows/macOS installer execution remain pending. Multisample PCM is preloaded;
the separate forward-only transport is not a per-voice disk sampler. This is
a developer release, and crates are not yet published to crates.io. No JUCE
feature-parity claim is made.

See [examples and setup](../../README.md), [release tools](../RELEASE.md),
[DSP](../DSP.md) and [sampling/streaming](../SAMPLER.md).
