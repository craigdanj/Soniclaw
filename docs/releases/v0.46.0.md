# Soniclaw 0.46.0 — Multitrack recording and takes

Release date: 2026-11-18.

## Added

Synchronized float32 track, master and input recording, bounded pre-roll, punch intervals, independent arming, immutable take manifests and non-destructive take selection, with live-session capture and off-callback retirement.

Read the [feature guide](../MULTITRACK_RECORDING.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.

## Compatibility

Workspace/internal package metadata advances to 0.46.0. Existing product identities remain stable. This remains pre-1.0; feature-specific schema changes and dependencies are described in the guide.
