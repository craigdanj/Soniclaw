# Soniclaw 0.93.0 — Oversampled modulated oscillator engines

Release date: 2026-11-20.

## Added

Adds reusable oversampled PWM, FM, phase modulation, phase warp, fractional hard sync and wavetable-morph sources with explicit generated-audio latency alignment and standalone spectral/audio examples.

Read the [feature guide](../DSP_OSCILLATORS.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
