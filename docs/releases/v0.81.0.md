# Soniclaw 0.81.0 — Submix and sidechain routing

Release date: 2026-11-20.

## Added

Add nested stereo submixes and master insert chains with per-edge delay compensation, smoothed gain/balance/mute/solo, peak meters and transactional routing drafts. Add current-block stock sidechain ducking with explicit latency constraints, routing-aware track operations, reference controls and measured allocation/timing examples.

Read the [feature guide](../DAW_MIXING.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
