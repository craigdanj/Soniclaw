# Soniclaw 0.34.0 — Waveform thumbnail cache

Release date: 2026-11-17.

## Added

Streaming multiresolution waveform peaks, fingerprinted atomic disk caches with corruption repair/eviction, latest-request background loading/cancellation, bounded PCM detail reads and a cached native waveform view.

Read the [feature guide](../WAVEFORM_CACHE.md) for workflows, public API, runnable examples, lifecycle/thread ownership, persistence/migration, bounds, errors and recovery.
