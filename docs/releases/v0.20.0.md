# Soniclaw 0.20.0 — MIDI I/O and sample scheduling

Release date: 2026-11-17.

## Feature

Bounded full MIDI 1 wire packets and SysEx, explicit driver-clock mapping, allocation-free sample queues, scheduled native/virtual output workers and persisted CC learning.

Read the [detailed guide](../MIDI_IO.md) for user workflow, API, runnable examples, lifecycle/thread ownership, persistence/migrations, limits, errors and recovery.

## Compatibility and migration

All workspace/internal package and format metadata advance to 0.20.0. Existing exported product and parameter identities remain stable. New fields/APIs and reader compatibility are described in the feature guide. No publication or untested platform acceptance is implied.

## Validation
