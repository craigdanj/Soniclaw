Run the examples from the workspace root using
`cargo run -p soniclaw-dsp-suite -- SUBCOMMAND NEW_DIRECTORY`.
Each example documents its output and fixture in the feature guide.

The cabinet example processes a synthetic plucked signal through the
WaveNet fixture and the blended IR. The sampler example writes independent
close, overhead and room stems from a unified group of takes. Use the live
granular, Ambisonics, and feedback examples to hear transport timing,
direction changes, and a saturated feedback path.

An optimized Rust run also evaluated the upstream classic A1 standard
fixture. Ninety-six thousand samples matched the pinned C++ reference
within 8.28e-7 maximum absolute error. The single-run throughput was
1.55× audio duration on this Linux runner.
[Performance and numerical record](validation/v0_137_0/nam-a1-reference.json).

## JUCE DSP capabilities for the next release series

| JUCE capability | Soniclaw extension |
|---|---|
| [Equiripple half-band FIR and polyphase allpass design](https://docs.juce.com/master/structjuce_1_1dsp_1_1FilterDesign.html) | Add peak-ripple-targeted coefficient design beside the existing least-squares FIR and fixed IIR profiles. Expose selectable per-stage oversampling filters. |
| [Shared convolution update queue](https://docs.juce.com/master/classjuce_1_1dsp_1_1ConvolutionMessageQueue.html) | Give multiple cabs or spatial voices a shared bounded worker for preparing and retiring IRs. Keep the existing per-instance audio crossfades. |
| [Lookup-table transforms](https://docs.juce.com/master/classjuce_1_1dsp_1_1LookupTableTransform.html) | Add a reusable prepared table with bounded interpolation and measured approximation error for waveshapers and hot nonlinear functions. |
| [Audio block subviews](https://docs.juce.com/master/classjuce_1_1dsp_1_1AudioBlock.html) | Extend the existing planar/interleaved blocks with checked, borrowed channel and sample-range views. |
| [First-order TPT filters](https://docs.juce.com/master/classjuce_1_1dsp_1_1FirstOrderTPTFilter.html) | Export a low-pass, high-pass, and all-pass one-pole that can be built into synths or driven at audio rate. |
| [Logarithmic ramps](https://docs.juce.com/master/classjuce_1_1dsp_1_1LogRampedValue.html) | Add reusable selectable logarithmic rise and fall curves for transitions and parameter automation. |
| [Configurable panning laws](https://docs.juce.com/master/juce__Panner_8h.html) | Expose a standalone processor with selectable center gain and sine, square-root and linear laws. |

Start with the half-band designers when the goal is more control over
the quality and latency of oversampling. A shared IR worker has the
most direct impact on a multi-cab guitar processor or a spatial mix.
