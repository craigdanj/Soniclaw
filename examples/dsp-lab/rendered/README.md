# DSP Lab rendered examples

Generated on Linux with `cargo run -p soniclaw-dsp-lab`. The WAVs are three-second
stereo examples at 48 kHz: source, SVF, ladder, FDN reverb, spectral gate, creative
chain, dynamics, low/mid/high crossover stems and wavetable unison. The JSON
files contain complete example projects and actual measurements; spectrum.csv
contains the normalized one-sided FFT of the pitch-analysis reference tone.
Run the program into a new directory to reproduce. These are demonstration
renders rather than a full acoustic/compliance evaluation.
