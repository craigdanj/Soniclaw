# Workbench rendered projects

Generated with the hardware-free `soniclaw-workbench --render NEWDIR` walkthrough.
Four preset JSONs include copied assets and can be opened from this folder in the
native workbench. Each preset WAV and the IR-crossfade WAV is two seconds at
48 kHz; offline stretch is three seconds and pitch shift remains two seconds.
All samples are first-party synthetic sources. render-report.json records actual
**debug-build** preview processing wall time (not optimized CPU benchmarks),
latencies and control-side IR retirement. Regenerate into a new folder.
